inkmath

把公式写成手写体的公式编辑器。打 LaTeX 命令（比如 \frac、\int 加空格）就能快速编辑，不会 LaTeX 也可以点工具栏。下面就是一个能用的编辑器，试试看。

npm install inkmath

输入方式

      

        
\alpha + 空格α。希腊字母都可以，直接打 alpha 也会变

        
\frac + 空格，或 /分式。Tab 从分子跳到分母

        
\int \sum + 空格带空位的模板。Tab 依次是下限、上限、主体，和 Word 一样

        
积分后打 dx自动在 dx 前加小空格

        
\sqrt \vec + 空格根号、向量，光标在里面

        
\R \Z \N + 空格ℝ ℤ ℕ，也可以 \mathbb + 空格 + 字母

        
^ / _上标、下标。空格、→ 或 Tab 跳出

        
先选中再点工具栏选中的内容会被套进模板，比如套上根号

      

    

    

      
在你的页面里用

      
import { createInkMath } from 'inkmath';
import 'inkmath/style.css';

const editor = await createInkMath(el, {
  value: '\\int_0^1 x^2\\,dx',
  font: 'caveat',
  onChange: (latex) => save(latex),
});

editor.setFont('kalam');
editor.setStyle({ roughness: 1.5 });

      
只想显示、不需要编辑时，用 renderLatex(el, latex)，下面这些就是用它画的。
