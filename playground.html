inkmath

A formula editor that writes in handwriting. Type LaTeX commands (such as \frac or \int followed by a space) to edit fast, or use the toolbar if you don't know LaTeX. The editor below is the real thing: try it.

npm install inkmath

Examples 

      
    

  


  

    

      
Typing

      

        
\alpha + spaceα. Every Greek letter works, and so does alpha without the backslash

        
\frac + space, or /A fraction. Tab moves from numerator to denominator

        
\int \sum + spaceA template with empty slots. Tab goes lower limit, upper limit, body, as in Word

        
dx after an integralGets its thin space automatically

        
\sqrt \vec + spaceA radical or vector, caret inside

        
\R \Z \N + spaceℝ ℤ ℕ, or \mathbb + space + a letter

        
^ / _Superscript, subscript. Space, → or Tab leaves it

        
Select, then click the toolbarThe selection goes inside the template, e.g. under a radical

      

    

    

      
On your page

      
Simplest: two tags. The toolbar can sit anywhere on the page and follows the formula you clicked.

      
<ink-math-toolbar></ink-math-toolbar>
<ink-math toolbar="none">\int_0^1 x^2\,dx</ink-math>

<script type="module">
  import 'inkmath/elements';
  import 'inkmath/style.css';
</script>

      
Or from JavaScript. The toolbar's content and words can be changed, or you can build your own:

      
import { createInkMath } from 'inkmath';

const editor = await createInkMath(el, {
  onChange: (latex) => save(latex),
});
editor.insert('\\sqrt{#@}');   // your own button

      
To show a formula without editing it, use renderLatex(el, latex). The ones below are drawn with it.
